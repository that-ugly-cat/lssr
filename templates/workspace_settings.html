Reviewers per stage
{% if is_owner %}{% endif %}

The dry run screens the records reviewers have already voted on, under the criteria as they stand now, and records the model's answers beside theirs without changing a single decision — it answers "would the model agree with us?". It costs an API call per record, so it is off unless a review wants to ask that question. Switching it off hides the button and the results; it does not delete them, and switching it back on shows the same numbers again.

1 = single screening (one human vote decides). 2 = blind double screening — two members must agree; if they disagree the record is flagged conflict for the owner to resolve. The model always pre-screens; with no human votes its decision stands.

Leave screening 2 empty to reuse screening 1's number. Set it when the two stages really differ — a corpus double-screened on title and abstract is often read once on full text, and requiring two votes there would leave every record pending however many reviewers had actually assessed it. Changing this number re-resolves stage 2 for every record.
